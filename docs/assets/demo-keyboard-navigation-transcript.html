Transcript: scripted keyboard navigation demo

What this video is. A scripted keyboard navigation demo of the remediated module, recorded automatically with a browser automation tool. It is not a screen reader demonstration: VoiceOver automation is unavailable on macOS 27, so no spoken output is shown, and no screen reader results are claimed anywhere in this repository. The captions and this transcript describe the scripted keyboard steps only. See the case study’s limitations section for the full list of what is pending human review.

  1. [00:00:00.000] Scripted keyboard navigation demo (automated). Not a screen reader demonstration: VoiceOver automation is unavailable on macOS 27, so no spoken output is shown. Captions describe the scripted keyboard steps.
  2. [00:00:05.454] The module home page loads. Every page starts with a skip link as the first tab stop.
  3. [00:00:05.926] Tab once — the skip link receives a visible focus outline.
  4. [00:00:06.256] Enter activates the skip link; focus jumps past the navigation to the main content.
  5. [00:00:06.517] Tab moves through the module navigation links.
  6. [00:00:06.775] Enter opens the Lesson page.
  7. [00:00:07.035] The lesson page: the study outline as semantic HTML with headings, lists, and a data table with a caption and scoped headers.
  8. [00:00:10.688] Tab reaches the Schools of Psychological Thought table; row and column headers are announced to assistive technology via scope attributes.
  9. [00:00:10.947] Arrow keys move between row headers in the table.
  10. [00:00:11.201] Next: the lecture slides page, where the 54-slide deck is HTML with real text, figure descriptions, and speaker notes.
  11. [00:00:11.487] Tab through the page; a details element expands the long description of a visual.
  12. [00:00:11.745] Enter expands the long description of the slide’s visual.
  13. [00:00:12.013] The expanded long description is visible to sighted users and read by screen readers alike.
  14. [00:00:15.676] The video page: a standard video element with a captions track, chapter buttons, and a transcript link.
  15. [00:00:16.146] Tab to a chapter button.
  16. [00:00:16.397] Enter starts playback from that chapter — the video element is fully keyboard operable.
  17. [00:00:16.651] The player controls are native and keyboard accessible; captions load from the transcript-derived WebVTT file.
  18. [00:00:21.503] Last: the practice quiz.
  19. [00:00:21.856] Tab to the first question’s radio group.
  20. [00:00:22.154] Arrow keys move within the radio group — radios use arrow-key navigation.
  21. [00:00:22.408] Space selects an answer.
  22. [00:00:22.661] Tab to the Check answer button.
  23. [00:00:22.911] Enter checks the answer; feedback appears in a live region that assistive technology announces.
  24. [00:00:23.164] Textual feedback is shown — never color alone. The score region updates politely.
  25. [00:00:29.016] Every check shown here is scripted; see the case study’s evidence section for the full audit, and the limitations section for what remains pending — including a human VoiceOver pass and a review by a daily assistive-technology user.

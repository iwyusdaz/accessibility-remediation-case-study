WCAG 2.1 AA conformance report — remediated module

Criterion-by-criterion conformance of the remediated module. This is the web version of report/conformance-report.md; the Markdown source is canonical. Markdown source.

This is not an official VPAT®/ACR. It follows the structure of a VPAT table for the author's portfolio, is written by an instructional designer (with AI assistance, disclosed), and carries no certification. Statuses use the VPAT vocabulary honestly: Supports / Partially Supports / Does Not Support / Not Applicable.

Evaluated contentThe remediated module: docs/module/ (index, lesson, slides, video, transcript, quiz)
"Before" basisThe original module as retrieved: docs/before/ (2011–2012 MIT OCW pages + 6 PDFs)
StandardWCAG 2.1 Level A + AA (W3C); WCAG 2.2 items noted as best practice, labeled "exceeds requirement"
Methodsaxe-core 4.11.1, Lighthouse 13.0.1, pa11y 9.0.0; scripted keyboard/reflow/contrast checks (Playwright 1.57.0); Label-in-Name check (2.5.3, Playwright); PDF tag-tree inspection (pypdf/pymupdf); DOM inspection. Full detail: audit/methodology.md
Dates2026-10-25 (2.5.1–2.5.4 rows and corrected 1.3.1/2.4.6 remarks: 2026-10-26 review round)
EvaluatorAI agent with scripted tools (labeled; see limitations). No human screen-reader pass yet; no daily-AT-user review yet.

Overall: Partially Supports WCAG 2.1 AA.

The remaining gaps are specific and disclosed:

  1. 1.2.2 / 1.2.5 (captions and audio description): captions are shipped with text from the publisher's official transcript and machine-aligned timings; the speech-to-text word-error-rate check (npm run eval:pending) and the human timing spot-check are pending. Audio description is provided as text, not as a recorded track.
  2. No screen-reader session evidence (Guidepup VoiceOver automation does not function on macOS 27; human protocol pending).
  3. No review by a daily assistive-technology user (invitation template provided).

Scope and honesty notes

  • "Before" statuses describe the module as retrieved (November 2012 Internet Archive captures of the 2011 MIT OCW Scholar pages).
  • The original site search (a Google Appliance form) was audited as part of the page it sits on; it is not functional inside the offline snapshot.
  • The case study site itself (docs/index.html, docs/faculty-quick-guide.html, docs/module/*, transcript pages) passes the same automated suite (0 axe violations, Lighthouse 100) and the same scripted checks — see audit/automated-results/after/.
